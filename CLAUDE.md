# CLAUDE.md

`astrbot_plugin_openai_oauth` is an AstrBot plugin that registers a
`openai_subscription_oauth` model provider. The user logs in with their ChatGPT account via
Codex OAuth (device code), and the AI calls draw on their subscription quota
instead of an API key. Intended for personal self-hosted use.

Development and commit conventions for this project live in AGENTS.md.
